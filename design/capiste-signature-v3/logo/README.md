# Capiste — logo Signature V3

Sources vectorielles du logo retenu (C teal et menthe, aiguille ambre), validées le 22 novembre 2026.

| Fichier | Usage |
| --- | --- |
| `capiste-logo-couleur.svg` | Logo horizontal sur fond clair. Copié dans `public/brand/logo-capiste.svg` pour l’en-tête et l’écran verrouillé. |
| `capiste-logo-fond-sombre.svg` | Logo horizontal sur fond teal ou sombre. |
| `capiste-logo-monochrome.svg` | Une seule couleur (impression, tampon). |
| `capiste-symbole.svg`, `capiste-symbole-fond-sombre.svg` | Symbole seul, à partir de 48 px. |
| `capiste-favicon-petites-tailles.svg` | Symbole redessiné pour 16 à 48 px : C en deux arcs, aiguille élargie, tuile teal. Copié dans `app/icon.svg` et `app/favicon.ico`. |
| `capiste-icone-app.svg` | Icône d’app à coins arrondis (`purpose: any`, 192 et 512 px). |
| `capiste-icone-ios.svg` | Icône carrée pleine pour iOS (180 px) : iOS arrondit lui-même les coins. |
| `capiste-icone-maskable.svg` | Icône Android adaptative : fond plein, symbole à 54 % dans la zone sûre. |

Couleurs du logo : teal profond `#0B5F5D`, teal `#1FA79A`, menthe `#D6F3EB`, ivoire `#FBF7EE`, ambre `#FFC857`. La version petites tailles utilise une menthe plus soutenue (`#7FD3C4`) pour rester distincte de l’ivoire à 16 px.

Le logo horizontal et le symbole proviennent d’une vectorisation de l’image de référence : quelques irrégularités de contour restent visibles au-delà de 500 px (pointes des croissants, lettres du mot). Ils conviennent à l’app ; pour l’impression grand format ou la communication, prévoir un redessin des contours.
